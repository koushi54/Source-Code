# Erase Itself — プログラム説明

## 開発環境・使用技術

### 開発環境

- **エンジン**: Unity（バージョン情報は掲載されていません）
- **言語**: C#

### 使用ライブラリ・機能

- **LitMotion**: ボタン、カメラ、UI、ライトのアニメーション
- **UniTask**: クリア・ゲームオーバー演出の順次実行
- **R3**: パラメータ変化とボタンクリックの購読
- **Cinemachine**: クリア演出用のカメラ
- **TextMeshPro / Input System**: 表示テキストと入力

---

## 担当範囲

このフォルダには、ポーズメニュー、ゲームクリア・ゲームオーバー演出、残量に応じた強さの更新、ボタンのホバー演出のスクリプトを掲載しています。`Kakky.*` のゲームデータや音声管理など、作品側の別システムと連携しています。

---

## コアシステム

### ポーズと入力

[`PauseService.cs`](Scripts/Pause/PauseService.cs) はメニューの表示時にカーソル状態を保存し、時間を停止します。閉じる際にカーソルと時間を戻します。[`ButtonAnimator.cs`](Scripts/Pause/ButtonAnimator.cs) と [`ButtonHoverAnimation.cs`](Scripts/InGame/ButtonHoverAnimation.cs) はポインターの出入りに合わせて位置や大きさを動かします。

### ゲームクリア

[`GameClearService.cs`](Scripts/InGame/GameClear/GameClearService.cs) はゲーム中の UI と音声を切り替え、演出を開始します。[`GameClearAnimator.cs`](Scripts/InGame/GameClear/Animation/GameClearAnimator.cs) はプレイヤーを中心としたカメラの回転、オブジェクトの上昇、クリアタイムと次ステージボタンの表示を順に実行します。次へ進む操作ではステージ番号を更新します。

### ゲームオーバーとパラメータ

[`GameOverService.cs`](Scripts/InGame/GameOver/GameOverService.cs) は演出、ゲーム中 UI の非表示、コンティニューボタンによる強さ・残量・タイマーの初期値への復帰を扱います。[`GameOverAnimator.cs`](Scripts/InGame/GameOver/Animation/GameOverAnimator.cs) は照明の暗転と UI の登場を演出します。[`StrengthCurve.cs`](Scripts/InGame/UI/StrengthCurve.cs) は残量の変化を購読し、AnimationCurve から強さを求めます。クリア・ゲームオーバーには、それぞれのサービスと同じインターフェースを持つモックも掲載しています。

## 掲載範囲について

`Scripts/` の抜粋であり、シーン、プレハブ、アセット、参照先のゲームデータや音声管理、パッケージ設定は含まれていません。このフォルダ単体では実行できません。
