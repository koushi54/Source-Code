# リグカジノ — プログラム説明

## 開発環境・使用技術

### 開発環境

- **エンジン**: Unity 6.3
- **言語**: C#
- **IDE**: Visual Studio Code

### 使用ライブラリ・機能

- **Netcode for GameObjects**: RPC による各クライアントへの UI・演出の反映、ネットワーク上のプレイヤー参照
- **DOTween**: パネル、ステージ、カメラ、テキストのアニメーション
- **UniTask**: 演出の順次実行と表示時間の制御
- **Cinemachine**: リザルトでのカメラ切り替えと追従
- **TextMeshPro**: クイズや警告の表示、文字メッシュを使った演出
- **ScriptableObject**: ゲーム設定、クイズ、からかい文句のデータ管理
- **Input System**: 掲載した入力設定と、エディター上での演出確認用入力

---

## 担当範囲

このフォルダには、ロビーのデバッグ支援、カジノの各種パネルとプレイヤー配置、船でのからかい演出、リザルトの進行・カメラ・ランキング演出、データ定義のスクリプトを掲載しています。外部の `Key.*`、`Cheat.*`、`AudioManager.*` などのシステムと連携する部分を含みます。

---

## コアシステム

### ロビーのデバッグ支援

[`DebugSupporter.cs`](Scripts/Lobby/DebugSupporter.cs) はデバッグコマンドを受けてプレイヤーごとの入力欄を生成します。サーバー側で入力を検証して各プレイヤーの所持金を更新し、船・リザルトへのシーン遷移後は全クライアントの読み込みを待って状態を切り替えます。

### カジノのクイズ・賭け金表示

[`QuizController.cs`](Scripts/Casino/QuizPanel/QuizController.cs) は問題番号からクイズデータを読み込み、選択肢の表示、選択枠の移動、決定時の演出を制御します。[`BetListPanel/MainController.cs`](Scripts/Casino/BetListPanel/MainController.cs) は賭け金の一覧を人数分生成します。表示・非表示は RPC で各クライアントへ伝え、DOTween で段階的に表示します。所持金がない場合の警告演出や、接続プレイヤーの配置処理も掲載しています。

### リザルトの順位発表

[`PlayerController.cs`](Scripts/Result/PlayerController.cs) は所持金順に上位プレイヤーを選びます。[`ResultManager.cs`](Scripts/Result/ResultManager.cs) は 3 位から 1 位へ順に、ステージとプレイヤーの上昇、カメラ切り替え、順位 UI、効果音、花火を進行します。各演出は RPC で表示先に反映し、[`CameraController.cs`](Scripts/Result/CameraController.cs) は Cinemachine の優先度と画面フェードを使って視点を切り替えます。

### データと文字演出

[`GameData.cs`](Scripts/SO/GameData.cs) は所持金・問題番号・各制限時間、[`QuizDatabase.cs`](Scripts/SO/QuizDatabase.cs) と [`QuizDatum.cs`](Scripts/SO/QuizDatum.cs) は問題文・選択肢・正解・倍率などを保持します。[`TeasingData.cs`](Scripts/SO/TeasingData.cs) の文句や表示位置から吹き出しを生成し、TextMeshPro の頂点操作で波打ち・揺れ・色変化を加える処理もあります。

---

## 掲載範囲について

このフォルダは Unity プロジェクト全体ではなく、`Scripts/` と `Inputs/` の抜粋です。シーン、プレハブ、アセット、一部の参照先コードやパッケージ設定は含まれていないため、このフォルダ単体では実行できません。
