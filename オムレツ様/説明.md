# オムレツ様 — プログラム説明

## 開発環境・使用技術

### 開発環境

- **エンジン**: Unity（バージョン情報は掲載されていません）
- **言語**: C#

### 使用ライブラリ・機能

- **LitMotion**: ステージ選択、カメラ、クリア UI のアニメーション
- **UniTask**: 演出とシーン読み込みの順次実行
- **Cinemachine**: 選択・クリア時のカメラ制御
- **ScriptableObject**: ステージ定義と開放条件
- **PlayerPrefs / JsonUtility**: クリア済みステージの保存と読み込み
- **TextMeshPro / Input System**: 表示テキストとエディター上の確認用入力

---

## 担当範囲

このフォルダには、ステージの定義・開放判定・進捗保存、ステージ選択時の操作と演出、ステージクリア時のカメラと UI の演出を掲載しています。シーンの追加読み込みと画面フェードは作品側の別システムと連携します。

---

## コアシステム

### ステージの開放と進捗保存

[`StageDefinition.cs`](Scripts/StageSelect/SO/StageDefinition.cs) は ID、表示名、遷移先シーン、前提ステージを定義します。[`StageProgressStore.cs`](Scripts/StageSelect/StageProgressStore.cs) はクリア済み ID を JSON にして PlayerPrefs に保存・復元し、[`StageClearRecorder.cs`](Scripts/StageSelect/StageClearRecorder.cs) が現在のステージのクリアを記録します。[`StageSelectManager.cs`](Scripts/StageSelect/StageSelectManager.cs) は記録と前提条件から「未開放・選択可能・クリア済み」を判定します。

### ステージ選択

[`StageSelectItem.cs`](Scripts/StageSelect/StageSelectItem.cs) は状態ごとの見た目を切り替え、ポインター操作をマネージャーへ伝えます。選択を確定するとフェード後にステージ選択シーンをアンロードし、選択したシーンを読み込みます。[`StageSelectAnimator.cs`](Scripts/StageSelect/StageSelectAnimator.cs) はホバー時の回転・拡大、未開放時の揺れ、選択時のカメラ移動と確定ボタンの表示を制御します。

### ステージクリア演出

[`StageClearAnimator.cs`](Scripts/StageClear/StageClearAnimator.cs) はクリア用カメラへの切り替え後、オムレツの周囲を回るカメラ、クリアテキスト、ステージ選択・次ステージのボタンを順に演出します。[`StageClearContainer.cs`](Scripts/StageClear/StageClearContainer.cs) がカメラと UI の参照・表示状態をまとめています。

---

## 掲載範囲について

`Scripts/` の抜粋であり、シーン、プレハブ、ステージ定義のアセット、参照先のシーン管理・画面フェード、パッケージ設定は含まれていません。このフォルダ単体では実行できません。
