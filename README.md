# Source-Code

制作した Unity / C# 作品のソースコードをまとめたポートフォリオです。各作品の `説明.md` に、掲載したコードの担当範囲、使用技術、主な処理を記載しています。

## 掲載作品

| 作品 | 掲載内容 | 詳細 |
| --- | --- | --- |
| Erase Itself | ポーズ、クリア・ゲームオーバー演出、残量と強さの連動、ボタン演出 | [説明](Erase%20Itself/説明.md) |
| Relay Shift | タイトル、設定画面の状態遷移と音量調整、開始・リザルト演出 | [説明](Relay%20Shift/説明.md) |
| リグカジノ | オンラインのクイズ・賭け金 UI、デバッグ支援、順位発表、データ管理 | [説明](リグカジノ/説明.md) |
| オムレツ様 | ステージ開放とクリア進捗の保存、ステージ選択・クリア演出 | [説明](オムレツ様/説明.md) |

## 使用技術

- **共通**: Unity、C#、TextMeshPro
- **演出**: LitMotion（Erase Itself、Relay Shift、オムレツ様）、DOTween（リグカジノ）、Cinemachine（一部作品）
- **非同期処理**: UniTask
- **データ・状態管理**: ScriptableObject、R3（Erase Itself）、State パターン（Relay Shift）、PlayerPrefs / JsonUtility（オムレツ様）
- **オンライン通信**: Netcode for GameObjects の RPC とプレイヤー参照（リグカジノ）

## 閲覧について

作品名のリンクから説明を読み、各説明内のリンクから対応するスクリプトへ進めます。ここに掲載しているのはスクリプトと一部の入力設定の抜粋です。Unity のシーン、プレハブ、アセット、`Packages/` などのプロジェクト設定や、コードが参照する作品側の別システムは含まれていません。リポジトリ単体でのビルド・実行はできません。
